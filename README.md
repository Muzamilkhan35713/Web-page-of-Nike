# Web-page-of-Nike

A small, static landing page inspired by Nike's product presentation. This repository is an educational demo focused on semantic HTML, responsive CSS, image handling, and publishing a static site with GitHub Pages.

## About this project

This project demonstrates a clean, minimal approach to building a product-style landing page without frameworks or build tools. It emphasizes:

- Semantic, accessible HTML structure
- Lightweight, maintainable CSS (see `stylish.css`)
- Optimized images stored in the `imge/` folder (AVIF files included for modern browsers)
- Simple deployment using GitHub Pages

The site is intentionally small and easy to fork or adapt for learning purposes.

## Key features

- Responsive layout suitable for desktop and mobile
- All assets included in the repository (no external dependencies)
- Clear file structure for learning and quick edits

## Technologies

- HTML5
- CSS3
- (Optional) Python's built-in HTTP server for local testing

## How to view locally

1. Open `indux.html` directly in your browser for a quick local preview.
2. For a more accurate test (recommended when using AVIF or other modern formats), serve the project folder with a simple HTTP server and open the page in your browser:

```powershell
python -m http.server 8000
# then open http://localhost:8000/indux.html
```

Running a local server ensures the browser handles image and MIME types correctly.
